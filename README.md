WayBus - Smart Public Transport Assistant

Problem Statement -
APP-03: Smart Public Transport Assistant
Develop a mobile application that helps users plan public transportation journeys. Users should be able to enter their source and destination and receive available route information, estimated travel time, and transfer requirements using either mock or available transportation data.
Expected Features:

- Source/destination selection
- Route search
- Estimated travel time
- Multiple route options
- Fare estimation
- Journey history
